# Button LED Toggle

## Description
An Arduino project that controls an LED using a push button.

The LED changes its state every time the button is pressed:
- First press: LED turns ON.
- Second press: LED turns OFF.

## Components
- Arduino Uno
- 1 Push Button
- 1 LED
- 1 Resistor

## Technologies
- Arduino C++
- Wokwi Simulator

## Logic
Uses INPUT_PULLUP and button state detection to implement Toggle (Latch) logic.
