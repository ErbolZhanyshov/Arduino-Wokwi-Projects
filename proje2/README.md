# Factory Safety System with LCD

Arduino ve Wokwi kullanılarak geliştirilen fabrika güvenlik sistemi simülasyonu.

### Components
- Arduino Uno
- 2 Push Buttons
- 3 LEDs (Red, Blue, Yellow)
- Buzzer
- LCD 1602 I2C

### Features
- Both buttons pressed: Safe mode.
- One button pressed: Warning mode with red LED and buzzer.
- No buttons pressed: Standby mode.
- LCD displays the current system status.

### Technologies
- Arduino C++
- Wokwi Simulator
